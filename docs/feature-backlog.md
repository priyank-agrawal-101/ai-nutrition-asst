# Gusto NutriBite: Feature Backlog

Capture feature ideas, enhancements, optional improvements, and product opportunities here, whether discovered during development, suggested by the AI coding agent, or added manually. This is a place for possibilities, including technical improvements and optimizations; it does not change the current scope.

The [product roadmap](product-roadmap.md) owns milestone direction. The [product specification](product-spec.md) owns requirements. A `docs/phase-wise-implementation-plan.md`, when created, owns detailed execution for the approved scope.

Use these values:

- **Category:** Feature, Enhancement, Technical, or Research.
- **Suggested priority:** High, Medium, Low, or Unassigned. This suggests attention, not a delivery commitment.
- **Status:** Idea (default), Approved, Deferred, or Closed. For Closed, note whether delivered, declined, or merged into another entry.
- **Target milestone:** Unassigned by default. A suggested M1, M2, or later target remains tentative until explicitly approved.

## Add or update an idea

1. Check existing entries and requirements first. Update a matching idea instead of creating a duplicate. An unfinished or defective approved requirement belongs in current delivery work, not this optional backlog.
2. Add one concise, actionable row with the next stable ID (`FB-001`, `FB-002`, and so on). Do not reuse IDs. State the change and expected value in a sentence; select a category and start with Idea status.
3. Leave priority and milestone Unassigned when unknown. Use notes for relevant links, dependencies, or who suggested it; no separate proposal document is required.
4. After an explicit decision, update the row and link the decision in notes. Approved means the recorded scope and target were approved; it does not imply work has started. Link the relevant roadmap milestone or implementation-plan entry when promoted.

## Scope rules

- Adding an idea does not authorize implementation. Usefulness alone is not a reason to expand current work.
- Capture new ideas here instead of inserting them directly into the implementation plan.
- Do not move approved requirements here because they are difficult to implement.
- Promote an idea into a roadmap milestone or the implementation plan only after explicit approval from the project owner. A priority, suggested target, or AI recommendation is not approval.
- Keep one entry per idea. Refine existing rows and link detailed requirements or decisions rather than copying them.
